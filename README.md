# 中式灵异小说顶级编剧 Skill V2.0

本技能包用于创作、续写、改稿和审校中式灵异、民俗恐怖、志怪悬疑、都市怪谈及架空历史鬼怪小说。

## 目录
```text
chinese_supernatural_screenwriter_skill_v2/
├── SKILL.md
├── README.md
├── references/
│   ├── genre_modes.md
│   ├── folklore_research.md
│   ├── monster_design.md
│   └── story_engine.md
└── templates/
    ├── chapter_template.md
    ├── entity_dossier.yaml
    ├── handoff_template.yaml
    └── review_scorecard.md
```

## 导入
1. 下载并解压 ZIP。
2. 将整个目录导入支持 Skill 的智能体平台。
3. 确保 `SKILL.md` 位于技能根目录。
4. `references/` 与 `templates/` 必须一起保留。
5. 在智能体系统提示词中加入：  
   `当任务涉及中式灵异、民俗恐怖、志怪悬疑或都市怪谈时，启用 chinese-supernatural-screenwriter Skill；先判断故事模式，再核查民俗来源，最后进行创作。`

## 使用时建议给出的信息
- 故事模式：现实社会 / 架空历史 / 半现实民俗悬疑
- 地域与时代
- 主角身份与核心目标
- 想使用的民俗原型（不确定可让 Skill 研究）
- 篇幅：短篇 / 单元故事 / 长篇连载
- 惊悚强度与尺度
- 希望结尾的主题方向

## 当前版本的核心改进
- 不再绑定《九天葬神录》原有玄幻世界观。
- 将现实社会灵异、架空历史灵异、半现实民俗悬疑分开处理。
- 新增鬼怪原型考据、复合鬼怪融合、鬼怪立体化档案。
- 新增感官恐怖设计、爆款故事引擎、章节钩子和审稿评分表。
- 将现实题材“回到人心与社会”设为强制主题要求。
