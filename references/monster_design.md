# 鬼怪立体化与恐怖场景设计手册

## 1. 鬼怪不是一张立绘

每个重要鬼怪至少要有：
- 第一印象：读者第一次看到/听到它时的异常。
- 轮廓特征：一个最容易记住的视觉标记。
- 局部细节：皮肤、牙齿、指甲、衣物、头发、眼睛、关节等。
- 动作习惯：它如何站、走、转头、呼吸、等待、靠近。
- 声音特征：声音从哪里来，是否与口型一致，是否模仿熟人。
- 气味/温度：出现时环境发生什么变化。
- 行为逻辑：它为什么这样做，而不是随便攻击。
- 禁忌规则：人做错什么会触发危险。
- 反常细节：至少一个不符合读者预期、但能被后文解释的特征。
- 人性映照：它的执念、行为或形成原因映照什么人间问题。

## 2. 恐怖递进五阶段
1. **异常**：门缝里多出一只鞋；楼上脚步停在自己头顶；家中物品位置不对。
2. **重复**：同一异常连续出现，证明不是偶然。
3. **靠近**：异常开始回应主角的行为，距离缩短。
4. **规则**：主角发现某个行为会触发后果，尝试验证。
5. **代价/反转**：规则被利用、误解或揭示更深层原因。

## 3. 感官描写原则
- 每个恐怖场景选择2—3种主感官，不要每段把五感全写一遍。
- 用动作代替空泛形容词。例如，不写“它非常恐怖”，写它的脖子先转过来，肩膀隔了半秒才跟上。
- 细节必须服务识别、氛围、规则或伏笔。
- 留白比全貌展示更有效；关键时刻才揭示完整形态。
- 不用纯粹恶心的生理细节堆量，除非题材和情节确有必要。

## 5. 反套路要求
同一作品内，避免连续重复同类惊吓装置。建立“恐怖手法轮换表”：空间错位、声音误导、时间异常、熟人模仿、仪式失效、物件变化、规则陷阱、身体感知异常、社会关系恐怖等轮换使用。
