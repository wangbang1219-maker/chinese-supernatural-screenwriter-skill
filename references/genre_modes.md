# 题材模式与结尾策略

## 1. 现实社会灵异

### 定义
现实世界作为唯一已确认的客观框架。故事可以出现无法解释的体验，但不得自动将超自然当作事实。

### 可用解释层
- 人为：诈骗、报复、犯罪、利益操控、造谣、伪装。
- 心理：创伤、愧疚、恐惧、记忆偏差、群体暗示。
- 环境：建筑结构、光影、声学、气体、设备故障、自然现象。
- 社会：家庭控制、邻里排斥、制度缺位、信息不对称。
- 开放：主要现实因果已经解释，但保留一个无法验证的小异常。

### 结尾公式
异常事件的真相/可确认部分 + 人物承担后果 + 现实关系变化 + 一个具象意象回响。
禁止用作者说教代替人物命运。

## 2. 架空历史灵异

### 定义
明确存在超自然规则的架空时代。可以参考真实历史文化，但地名、政权、人物、仪式可作虚构设计。

### 规则清单
- 鬼从何来？
- 鬼是否保留生前记忆？
- 鬼能否说谎、交易、守约？
- 鬼如何影响活人？
- 鬼是否受时辰、地域、器物、血缘或仪式限制？
- 人如何辨认鬼与伪装者？
- 驱逐、安抚、封禁或消灭的代价是什么？
- 阴阳秩序由谁维护？是否腐败或失效？

### 结尾策略
回收核心禁忌与因果，揭示人物选择的代价，并通过鬼与人的镜像关系形成历史/伦理主题。

## 3. 半现实民俗悬疑

让民俗实践成为现实人物行为的一部分。仪式、禁忌、器物要有具体地域和文化背景。超自然真相可延迟揭晓，但作者必须有内部答案。

## 4. 题材混合禁忌
不得在没有解释的情况下，把佛教地狱、道教阴司、地方祖灵、少数民族祖先信仰和现代网络怪谈拼成同一套古已有之的体系。若跨文化融合，需在故事中说明这是架空世界的重新整合。
